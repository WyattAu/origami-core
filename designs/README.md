# Design library

Civilian origami design library. One directory per design:

```
designs/<category>/<design-name>/
  design.fold      FOLD JSON (vertices/edges/assignments/faces)
  meta.toml        name, license, status, civilian, controlled
```

## Placement rule (hard)

**Defense-related or finance-related designs never enter this repo.**
They go to the private Forgejo repo:

    git@forgejo:wyatt/origami-controlled.git

Rationale: technical data for arms applications is export-controlled
(ITAR/EAR and equivalents); publishing it in a public repo is a legal
violation before anyone even downloads it. When in doubt, place the
design in the controlled repo. `meta.toml` must carry
`civilian = true` and `controlled = false`; a missing flag means
treat-as-controlled. Agents: AGENTS.md item 6 binds you to this rule.

## Gates

Every committed `*.fold` must pass the repo's own validators
(structure, Maekawa, Kawasaki): enforced by
`crates/origami-cli/tests/designs.rs` on every CI run. Check by hand:

    cargo run -p origami-cli -- fold-check --all designs

## Licensing

Design files default to `CC0-1.0` (declare it in `meta.toml`; other
open licenses allowed). Designs under controlled licenses do not belong
here either: this repo is Apache-2.0 code plus CC0 data.

## Seed design

`examples/miura-ori/` is generated by `tools/make_miura.py`, which
verifies Maekawa and Kawasaki numerically before writing. Regenerate:

    python3 designs/tools/make_miura.py
